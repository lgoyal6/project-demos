What this demonstrates

The native SwiftUI port is Laksh Goyal’s work. The physiology model originates in Alan Moazzam’s Night Shift Coach. Schedule and phase-shift calculations run the extracted original model. Sun times use a fixed San Diego example dated June 21, 2026; no location is collected. This browser companion does not run iOS notification or CoreLocation services. It is an educational model, not personalized medical guidance.
