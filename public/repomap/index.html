About this demo

Live original extraction code with a temporary-file adapter. Up to six small files are parsed in an isolated temporary directory and removed afterward. The original regex extractor is unchanged. Rust files are discovered but have no extraction branch; export detection and call-like comments have known limitations. Source-line highlighting locates the import text in the editor; the original graph does not return source spans. VS Code and IBM Bob are not connected.
