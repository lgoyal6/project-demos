About this demo

Recorded native C++ execution on synthetic netlists. Three seeded examples were run with the original solver. Rejected outputs stay rejected. Moving cells performs a new browser overlap check; it does not rerun the solver. Connection lines use the original net endpoints and seeded pin offsets. These examples are separate from the challenge benchmark.
